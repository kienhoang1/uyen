# Thư mục Builds

Thư mục này chứa bản biên dịch Windows Standalone (`.exe`) khi bạn chạy `Tools/build-windows.ps1` hoặc Build trực tiếp trong Unity 6 Editor trên máy Windows.

Lưu ý: Môi trường AI Studio chạy trên Linux Container nên không thể tự biên dịch ra file `.exe` của Unity Windows. Hãy làm theo hướng dẫn trong `Documentation/04_OBS_AND_WINDOWS_RELEASE_CHECKLIST.md`.
