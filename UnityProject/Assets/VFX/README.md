# UnityProject/Assets/VFX, Audio, Materials, Prefabs, Settings
- `Audio/`: Lưu SFX va chạm, quà tặng, 5 tuyệt chiêu và nhạc nền đấu trường.
- `Materials/`: Lưu PBR Materials URP (Skin, Hair, Athletic Suit, Stadium Floor).
- `Prefabs/`: Lưu `BoyFighter.prefab`, `GirlFighter.prefab`, và VFX Prefabs dùng với `ObjectPooler`.
- `Settings/`: Lưu cấu hình URP Asset (`URP_High.asset`, `URP_Balanced.asset`).
- `VFX/`: Lưu Particle Systems cho ThunderPush, EnergyShield, RageMode, UltimateBlast, Recovery.
